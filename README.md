# 🐍 About This Repository

This repository documents my journey of learning Python through structured practice, hands-on coding, and mini projects.

It covers Python fundamentals, Object-Oriented Programming (OOP), file handling, exception handling, modules, comprehensions, and practical applications that strengthen problem-solving and programming skills.

The goal of this repository is to build a strong Python foundation for Data Science, Machine Learning, and AI Engineering.
